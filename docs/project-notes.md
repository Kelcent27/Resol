# Resol project notes

This project is designed to be a practical MVP foundation for a reminder productivity platform.

## Planned modules

- Reminder management
- Notes and agenda tracking
- Calendar planning interface
- AI-powered productivity assistant
- Chat and collaboration
- Live meetings
- Authentication
- Notifications

## Suggested next steps

1. Add PostgreSQL integration using the included schema.
2. Implement real JWT auth with hashed passwords.
3. Connect the front-end to the backend with fetch and WebSocket APIs.
4. Add OpenAI API integration for the AI assistant.
5. Add a real video/meeting provider such as Jitsi or Zoom.
6. Expand the design with a polished dashboard and mobile optimizations.
